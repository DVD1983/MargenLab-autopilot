# Skill: Copy Venta Argentina

## Tono
- Voseo rioplatense, cercano, sin ser informal de más
- Emojis moderados (1 por mensaje)
- CTA siempre con link

## Estructuras que convierten
- WhatsApp: Dolor + Solución + Urgencia + Link
- Reels: Hook 3 seg + Prueba + Beneficio + CTA
- Email: Asunto con número ($896k perdidos), cuerpo corto, 1 CTA

## Plantillas
- Carrito: "Che {nombre}, dejaste {producto}... ¿Te lo guardo con 10% OFF hasta hoy 18hs? 👉 {link}"
- Upsell: "Ya que llevás {producto}, la mayoría se lleva {complemento} y se ahorra envío"
